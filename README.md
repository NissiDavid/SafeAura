# SafeAura
SafeAura is women safety web application developed using HTML,CSS and JavaScript.

## Features
- Emergency SOS
- Fake Call Feature
- Trusted Contact Saving
- Safety Tips
- Responsive UI

  ## Technologies Used
  - HTML
  - CSS
  - JavaScript
  - GitHub
  - Netlify
